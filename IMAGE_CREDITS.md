# Image credits

The canonical, machine-readable record is [`_data/image_credits.yml`](_data/image_credits.yml); it is
rendered on the website at `/image-credits/` and next to each figure. This file summarises it.

## Schematic model visualizations (original)

Generated by [`bin/research_figures.py`](bin/research_figures.py) (numpy, matplotlib, pillow). They are
illustrations of textbook models, not research data, and are labelled "Schematic" on the site. Each
figure exists in a `-card` (16:10, unlabelled) and a `-figure` (labelled) variant in
`assets/img/research/`.

| File stem                | Model                                                                                                                        |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| `schematic-dwave`        | Square-lattice band, t′/t = −0.3, filling n = 0.85; Fermi contour coloured by Δ(k) = Δ₀(cos kₓ − cos k_y)                    |
| `schematic-altermagnet`  | Simplified d<sub>x²−y²</sub>-type altermagnet, E↑/↓ = −2t(cos kₓ + cos k_y) − μ ± λ(cos kₓ − cos k_y), λ/t = 0.6, μ/t = −2.4 |
| `schematic-chern-ribbon` | Qi–Wu–Zhang Chern insulator, m = 1 (Chern number 1), ribbon of 40 sites; colour = edge localisation                          |

The script asserts the physics it draws (filling, nodal lines, spin degeneracy on the diagonals, Chern
number, ribbon/bulk consistency, edge localisation of in-gap states) before writing any file.
